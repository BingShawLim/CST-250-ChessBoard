# CST-250 Activity 2 - Chess Board (Bing Shaw Lim)

| Project | Purpose |
|---|---|
| ChessBoardClassLibrary | Models (CellModel, BoardModel) and Services/BusinessLogicLayer (BoardLogic) shared by both apps |
| ChessBoardConsoleApp | Text version: choose a piece and location, see the legal moves on an outlined board |
| ChessBoardGUIApp | Windows Forms version with a grid of buttons and seven color themes |
| ChessBoardClassLibrary.Tests | xUnit tests for BoardLogic |

Open `ChessBoard.sln` in Visual Studio 2022, right-click the app you want and choose **Set as Startup Project**, then press F5.
